StickLaugh Studio 9.0

1. ZIP extract karke StickLaughStudio folder kholo.
2. Node.js24, Chrome aur FFmpeg/ffprobe install hone chahiye.
3. Windows: START_WINDOWS.bat. Mac/Linux: bash start.sh
4. http://127.0.0.1:3001 kholo.
5. Nayi story mein Automatic length default hai: Gemini story ke beats ke hisaab
   se duration chunta hai. Manual choose karke target seconds bhi de sakte ho.
6. 60 fps ya120 fps choose karo; director mein export se pehle badal bhi sakte ho.
7. Reference-style radio buttons se silent/selective colour ya coloured cartoon
   choose karo. Try the tested demo bundled plan load karta hai, nayi story nahi.
8. Listen to this scene's sounds se actual clips suno. Preview aur scenes dekho,
   phir Render dabao. Bundled sample ko API keys nahi chahiye.
